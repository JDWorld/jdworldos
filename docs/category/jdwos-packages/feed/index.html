Sia nella versione nativa da repository Arch che nella variante sandbox Flatpak, Kodi tende spesso a congelarsi nella fase di uscita mentre tenta di rilasciare i flussi audio PipeWire o i plugin di rete (come inputstream.adaptive o PVR IPTV). Questo freeze lascia il processo appeso in memoria, impedendo al sistema operativo di avviare i timer di spegnimento automatico.

Come funziona il pacchetto jdwos-kodiwd:

  • Rilevamento Universale: Riconosce automaticamente se sul sistema è installato Kodi nativo (/usr/lib/kodi/kodi.bin) oppure Flatpak (tv.kodi.Kodi), lanciandolo direttamente senza aprire finestre di terminale superflue.
  • Monitoraggio Dinamico dei Log: Resta in ascolto silenzioso sul file kodi.log senza impostare limiti di tempo alla visione.
  • Intervento Chirurgico in 3 Secondi: Nel momento esatto in cui premi Esci (o scatta il timer interno di Kodi), il watchdog concede 3 secondi per una chiusura pulita; se il processo resta bloccato, interviene con un kill forzato (SIGKILL), liberando istantaneamente le risorse e il risparmio energetico del desktop.
